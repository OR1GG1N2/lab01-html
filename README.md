# Практична робота №1–10

## Про проєкт

Мінісайт з динамічним каталогом проектів, реалізованим на основі асинхронної роботи з JSON-даними, fetch API та управління станом інтерфейсу.

## Що реалізовано

### Базова структура (практична №1)
- HTML5 семантична розмітка
- 3+ сторінки (головна, про мене, контакти)
- Форма з валідацією
- Медіа-контент (відео, аудіо)
- Таблиці

### JavaScript інтерактивність (практична №8)
- Обробка подій (click, input, change)
- Мобільне меню з бургер-кнопкою
- Перемикач теми (світла/темна) з localStorage
- Модальні вікна
- Валідація форми
- Збереження чернеток форми у localStorage
- Акордеон для FAQ

### Асинхронна робота з даними (практична №9–10)

#### ✅ 1. JSON-дані каталогу
- Файл `data/projects.json` з 12 проектами
- Структура: id, title, category, description, image, rating, level, featured, date, technologies

#### ✅ 2. Асинхронне завантаження через fetch()
- Функція `loadProjects()` у `api.js`
- Обробка помилок через try/catch
- Показ стану завантаження

#### ✅ 3. Стани інтерфейсу
- **Loading**: спінер під час завантаження
- **Error**: повідомлення про помилку з кнопкою повтору
- **Empty result**: стан при відсутності результатів

#### ✅ 4. Динамічний рендеринг карток
- Функція `renderProjects()` у `catalog.js`
- Генерація HTML на основі даних JSON
- Карточки з зображенням, назвою, описом, рейтингом, технологіями

#### ✅ 5. Пошук у реальному часі
- Поле пошуку з атрибутом `data-search`
- Пошук за назвою, описом та технологіями
- Результати оновлюються без перезавантаження

#### ✅ 6. Фільтрація за категоріями
- Select для вибору категорії (Frontend, Backend, Design, Усі)
- Динамічне оновлення сітки
- Empty-state при відсутності результатів

#### ✅ 7. Сортування
- 7 варіантів сортування:
  - По даті (новіші/старіші)
  - По назві (А-Я / Я-А)
  - По рейтингу (спадаючи/зростаючи)
  - По рівню складності

#### ✅ 8. Система обраного (Favorites) з localStorage
- Кнопка серця на кожній карточці
- Збереження в localStorage ключ `projectFavorites`
- Перевірка стану при рендерингу
- Можливість додавання/видалення

#### ✅ 9. Пагінація
- Відображення по 6 елементів на сторінці
- Кнопки "Назад" / "Далі" та номери сторінок
- Коректна робота з фільтрами та пошуком

#### ✅ 10. Модальне вікно з деталями проекту
- Нажатя кнопки "Детально" відкриває модальне вікно
- Повна інформація про проект
- Кнопка додавання в обране
- Закриття на Escape та клік за межами вікна

## Як використовувати

### Перегляд каталогу
1. Перейдіть на сторінку **Каталог** з головного меню
2. Використовуйте пошук для пошуку за назвою чи технологією
3. Фільтруйте за категоріями
4. Сортуйте за різними параметрами
5. Натисніть серце (♡) щоб додати в обране
6. Натисніть "Детально" для перегляду повної інформації

### Перегляд обраного
1. Перейдіть на сторінку **Обране**
2. Оглядайте збережені проекти
3. Видаліть з обраного натисканням на серце (♥)

### Функціональність localStorage
- **Тема**: зберігається тема користувача при перемиканні
- **Обране**: список ID обраних проектів
- **Чернетки форми**: дані форми контакту зберігаються автоматично

## Пояснення коду

### Асинхронна загрузка даних
```javascript
// api.js
async function loadProjects() {
  const response = await fetch('./data/projects.json');
  if (!response.ok) throw new Error('Помилка завантаження');
  return response.json();
}
```

### Рендеринг карток з масиву
```javascript
// catalog.js
const html = projects.map(project => `
  <article class="project-card">
    <h3>${project.title}</h3>
    <p>${project.description}</p>
  </article>
`).join('');
```

### Пошук та фільтрація
```javascript
function filterProjects(projects, query, category) {
  return projects.filter(p => {
    const matchQuery = p.title.toLowerCase().includes(query.toLowerCase());
    const matchCategory = category === 'all' || p.category === category;
    return matchQuery && matchCategory;
  });
}
```

### Система обраного
```javascript
// api.js
function toggleFavorite(projectId) {
  const favorites = getFavorites(); // Читання з localStorage
```
