## 🔧 Первинне налаштування

### Крок 1: Встановити json-server глобально

```bash
npm install -g json-server
```

**Перевірка встановлення:**
```bash
json-server --version
```

Повинна вивести версію, наприклад: `1.0.0-alpha.1`

---

## ▶️ ЗАПУСК ПРОЕКТУ

### Варіант 1: Автоматичний запуск (рекомендується)

#### 🖥️ На Linux/Mac:
```bash
chmod +x start.sh
./start.sh
```

#### 🖥️ На Windows:
```bash
start.bat
```

Скрипти автоматично запустять:
1. REST API сервер (json-server) на **порті 3000**
2. Веб-сервер на **порті 8000**

---

### Варіант 2: Ручний запуск (у двох терміналах)

#### Термінал 1: Запустити REST API
```bash
json-server --watch db.json --port 3000
```

**Вивід:**
```
  Loading db.json
  Done

  Resources
  http://localhost:3000/items

  Home
  http://localhost:3000

  Type s + enter at any time to create a snapshot of the database
  Watching...
```

#### Термінал 2: Запустити веб-сервер

**Варіант A: Python (рекомендується)**
```bash
python -m http.server 8000
```

Або на Windows (якщо python не працює):
```bash
python3 -m http.server 8000
```

**Варіант B: Live Server (якщо встановлено)**
```bash
live-server
```

**Варіант C: Node.js (http-server)**
```bash
npm install -g http-server
http-server -p 8000
```

## 🔍 ПЕРЕВІРКА REST API У БРАУЗЕРІ

### Відкрити DevTools (F12) → Network

1. **Завантаження даних** (GET запит)
   ```
   GET http://localhost:3000/items
   ```
   - Status: **200**
   - Відповідь: JSON масив з 10 проектами

2. **Створення проекту** (POST запит)
   ```
   POST http://localhost:3000/items
   ```
   - Headers: `Content-Type: application/json`
   - Body: JSON об'єкт з даними проекту
   - Status: **201** або **200**

3. **Оновлення проекту** (PATCH запит)
   ```
   PATCH http://localhost:3000/items/1
   ```
   - Headers: `Content-Type: application/json`
   - Status: **200**

4. **Видалення проекту** (DELETE запит)
   ```
   DELETE http://localhost:3000/items/1
   ```
   - Status: **200**

## 📝 ПРИКЛАДИ CURL КОМАНД

Ви можете протестувати API безпосередньо з терміналу:

### GET — Отримати всі проекти
```bash
curl http://localhost:3000/items
```

### GET — Отримати один проект
```bash
curl http://localhost:3000/items/1
```

### POST — Створити новий проект
```bash
curl -X POST http://localhost:3000/items \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Новий проект",
    "category": "frontend",
    "description": "Опис",
    "rating": 4.5,
    "level": "Середній",
    "image": "https://example.com/img.jpg",
    "date": "2026-06-03",
    "technologies": ["HTML", "CSS"],
    "featured": false
  }'
```

### PATCH — Оновити проект
```bash
curl -X PATCH http://localhost:3000/items/1 \
  -H "Content-Type: application/json" \
  -d '{"rating": 5.0, "title": "Оновлена назва"}'
```

### DELETE — Видалити проект
```bash
curl -X DELETE http://localhost:3000/items/1
```

## 🐛 РОЗВ'ЯЗАННЯ ПРОБЛЕМ

### ❌ "json-server не знайдено"
**Рішення:**
```bash
npm install -g json-server
```

### ❌ "Порт 3000 вже використовується"
**Рішення:** Використовувати інший порт
```bash
json-server --watch db.json --port 3001
```
Тоді оновити `API_BASE_URL` у `js/api.js`:
```javascript
const API_BASE_URL = 'http://localhost:3001/items';
```

### ❌ "Порт 8000 вже використовується"
**Рішення:** Використовувати інший порт
```bash
python -m http.server 8001
```

### ❌ Каталог порожній (немає проектів)
**Рішення:** Перевірити:
1. ✅ json-server запущений та показує ресурс `/items`
2. ✅ `db.json` містить дані в масиві `items`
3. ✅ DevTools → Network показує успішний GET запит

### ❌ Зміни не зберігаються
**Рішення:**
1. ✅ Перевірити, що json-server показує "Watching..."
2. ✅ Перевірити, що файл `db.json` записується (він автоматично оновлюється)
3. ✅ Оновити браузер (F5)

### ❌ CORS помилки
Якщо бачите помилку про CORS, це означає, що фронтенд та API на різних портах. Це нормально! json-server за замовчуванням дозволяє CORS.
