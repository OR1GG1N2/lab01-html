## 📱 Як тестувати

### 1. Перегляд каталогу
```bash
# Відкрийте у браузері:
http://localhost:8000/pages/catalog.html
```

### 2. Тестування функцій
- **Пошук**: Введіть "JavaScript", "API", "HTML" в поле пошуку
- **Фільтрація**: Виберіть категорію (Frontend/Backend/Design)
- **Сортування**: Виберіть порядок сортування
- **Обране**: Натисніть ♡ щоб додати в обране
- **Деталі**: Натисніть "Детально" для модального вікна
- **Пагінація**: Перейдіть на інші сторінки

### 3. Перевірка localStorage
```javascript
// У консолі браузера (F12):
localStorage.getItem('projectFavorites') // Показує [id1, id2, ...]
localStorage.getItem('siteTheme')        // Показує поточну тему
```

### 4. Стани системи
- **Loading**: Сервер повинен повернути дані (близько 50-100мс)
- **Error**: Спробуйте змінити шлях у `api.js` на неправильний
- **Empty**: Пошук по "XXXXXX" або виберіть порожну категорію
